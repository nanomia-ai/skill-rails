# Product brief

## Product request

Create a bookmark CLI for one user. It must store a bookmark by stable id, retrieve the same HTTPS URL, and return no value for an unknown id. Preserve the phrase 'save once, retrieve exactly'. The brief must state the HTTPS-only acceptance boundary. Storage location, retention period, and import support are undecided and must remain unknown.

## Acceptance boundary

Only HTTPS URLs are inside the acceptance boundary.

## Unknowns

- Storage location: unknown
- Retention period: unknown
- Import support: unknown
