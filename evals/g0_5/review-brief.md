# Review task

Inspect the supplied skill artifact as if you were maintaining it for the first time. Find behavior defects. For every finding, provide:

- exact source coordinate;
- one-sentence claim;
- a concrete state that reproduces it;
- expected and actual behavior;
- whether the result is mechanically reproducible.

Answer the separate state questions. Do not infer that missing evidence means success. Do not consult sibling forms, the oracle, previous reviews, repository history, or conversation about intended defects.
