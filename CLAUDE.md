# Claude Code project instructions

Read [AGENTS.md](AGENTS.md) before changing this repository. It is the canonical project instruction file and applies to Claude Code as well.

In particular:

- preserve the product intent and mechanize reliably checkable rules instead of growing prose;
- make changes at the owning abstraction rather than layering local exceptions;
- keep all writes inside this repository and preserve existing user work;
- do not commit, push, publish, or deploy unless the user explicitly requests it;
- distinguish structural checks from real behavior evidence;
- when creating or revising a skill README, read [references/readme-authoring.md](references/readme-authoring.md) completely and follow the user's requested voice and priorities first.
